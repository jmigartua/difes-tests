Spectra and models

The two kinds of file the program lives on: measured or computed spectra, and dielectric-function models with their parameters.

Spectra

A spectrum is an ascending wavenumber axis in \mathrm{cm}^{-1}, an intensity array, a kind saying what the intensity is, an optional uncertainty per point, an optional temperature and free metadata. The kinds are:

kind meaning range check
R normal-incidence reflectivity [0, 1]
E normal spectral emissivity [0, 1]
T transmission [0, 1]
eps1, eps2 real and imaginary part of \(\varepsilon\) —
chi1, chi2 real and imaginary susceptibility \(\chi = \varepsilon - 1\) —
n, k refractive index and extinction coefficient —
theta phase of the reflection coefficient, radians —
raw anything else (single beam, interferogram) —

Reading a bounded kind clamps small excursions outside [0, 1] (up to 0.01) and rejects larger ones with a message: an emissivity of 1.3 is a wrong column, not a measurement.

Reading files

difes info FILE --kind K [--unit U] [--cols ...] prints what the reader sees: the number of points, the range in \mathrm{cm}^{-1}, how many header lines were skipped, which columns were used. Use it before any other command on a new file.

The text reader takes any numeric table: whitespace or comma separated, any number of header lines (lines that do not start with a number are skipped), the first two or three numeric columns as x, y and yerr unless --cols says otherwise. The group’s emissivity CSVs have the angle in column 3 and wavenumber, emissivity and uncertainty in columns 4, 6 and 7; several angles share one file, so filter the angle first (the examples folder has a script that does it) or crop with --range.

difes convert FILE --kind K --unit nm -o OUT.txt rewrites a file in \mathrm{cm}^{-1} with the standard three columns; --to eV writes the x axis in another unit.

The text format written by difes

# x[cm^-1]  R  yerr  # name
100.0  0.9412  0.002
...

One header line, then columns; readable back by read_text with no options.

Models

A model is

\varepsilon(\omega) = \varepsilon_\infty \prod_j F_j(\omega) + \sum_k \chi_k(\omega),

a product of multiplicative factors (four-parameter phonon modes) on \varepsilon_\infty, plus a sum of additive susceptibilities (Drude, Lorentz, causal Gaussian, user formulas). The terms and their parameters:

kind parameters (\(\mathrm{cm}^{-1}\) unless stated) contribution
drude wp, gamma \(\chi = -\omega_p^2/(\omega^2 + i\gamma\omega)\)
lorentz w0, wp, gamma \(\chi = \omega_p^2/(\omega_0^2 - \omega^2 - i\gamma\omega)\); strength \(S = \omega_p^2/\omega_0^2\)
fpsq w_to, g_to, w_lo, g_lo factor \((\omega_{LO}^2 - \omega^2 - i\gamma_{LO}\omega)/(\omega_{TO}^2 - \omega^2 - i\gamma_{TO}\omega)\)
gaussian w0, A (dimensionless), sigma (FWHM) causal Gaussian band, Dawson function for \(\chi'\)
expr the formula's arguments after the variable the formula, evaluated by the math language

The equations, the passivity conditions and the FOCUS names of the same parameters are in Part II, Models.

The model file

{
  "name": "example",
  "eps_inf": {"value": 3.0, "lower": 1.0},
  "terms": [
    {"kind": "drude", "wp": 2000.0, "gamma": 150.0},
    {"kind": "lorentz", "w0": {"value": 450.0, "lower": 400, "upper": 500}, "wp": 600.0, "gamma": {"value": 20.0, "frozen": true}},
    {"kind": "gaussian", "w0": 1050.0, "A": 1.5, "sigma": 120.0},
    {"kind": "expr", "formula": "bump(x, A, xc) = A/(1 - i*(x - xc)/50)", "A": 0.1, "xc": 800.0}
  ]
}

A parameter is a bare number or an object with value, optional lower and upper bounds, frozen (true keeps it out of the fit) and error (written by the fitter). Default bounds keep frequencies, dampings, plasma frequencies and amplitudes non-negative and \varepsilon_\infty \ge 0; a bound may be widened or narrowed per parameter.

difes model example prints the example model; difes model FILE.json describes a file: every parameter with its bounds, frozen flag and fitted error, and the number of free parameters.

Naming a parameter

Parameters are addressed by path: eps_inf, or INDEX.KIND.NAME with the term’s position, for example 1.lorentz.w0. The same paths appear in fit reports, in sessions (set_parameter) and when linking parameters between models.

On this page

    What this is

    The test ledger of difes, a program for dielectric-function models, reflectivity, emissivity, Kramers–Kronig and fitting of infrared spectra, built as a personal project to give the group an open and documented counterpart of FOCUS. Every check the program has passed through is listed here with its grade, its data and its result, next to the validation pages the checks come from and the complete manual: how the app looks and works, and the physics it implements, equation by equation.
